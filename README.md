# Task 4: Classification with Logistic Regression

**AI & ML Internship – Elevate Labs**

## Objective
Build a binary classification model using Logistic Regression to predict whether a breast tumor is benign or malignant.

## Tools & Technologies
- Python
- Scikit-learn
- Pandas
- Matplotlib
- Google Colab

## Dataset
Breast Cancer Wisconsin Dataset (Kaggle).

## Implementation
- Data loading and preprocessing
- Handling unnecessary columns
- Train-test split
- Feature standardization
- Logistic Regression model training
- Model evaluation using confusion matrix, precision, recall, and ROC-AUC
- Classification threshold tuning
- Sigmoid function visualization

## Project Structure
- `README.md` – Project documentation
- `Task_4_Logistic_Regression.ipynb` – Jupyter Notebook
- `Task_4_Logistic_Regression_Screenshots.pdf` – Screenshot documentation
- `data.csv` – Breast Cancer Wisconsin Dataset

## Results
- Precision: 0.975
- Recall: 0.9286
- ROC-AUC: 0.9960
